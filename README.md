# 專案分析報告：原生家庭與催婚壓力對結婚意願之影響

## 1. 使用資料來源
本研究採用 **中央研究院「家庭動態資料庫 (PSFD)」** 2022 年度的資料進行分析：
*   **C2022 (子女問卷)：** 主要樣本來源，包含子女的結婚意願、個人基本資料、心理健康、經濟狀況及對父母衝突的回憶。
*   **RR2022 (父母問卷)：** 用於配對分析，提取父母對子女的感情評價、家庭總收入及父母自身的婚姻滿意度。
*   **配對樣本：** 最終成功配對且符合「未婚」篩選條件之有效樣本數為 **131** 戶（總分析樣本 149 筆）。

## 2. 資料處理方式
### 2.1 變數編碼 (Recoding)
*   **Likert 量表：** 統一調整編碼方向。例如「心情悶悶不樂」與「婚姻滿意度」等題項，皆調整為「數值越高代表程度越高」。
*   **二元變數：** 性別 (A01)、工作狀態 (C02r1) 等類別變數重新編碼為 0 與 1。
*   **經濟指標：** 將民國出生年份轉換為年齡；將區間型收入 (k23) 轉換為各區間中位數，並與具體金額題 (k22) 合併為 `k22_filled`。

### 2.2 遺漏值處理 (KNN Imputation)
針對非隨機缺失或關鍵變數進行補值：
*   **結婚意願 (d07)：** 透過 t-test 檢驗確認缺失值與填答值無顯著意願差異，採用 **KNN 填補 (k=5)**。
*   **家庭收入 (k22)：** 依據人力資本理論，選用「性別、年齡、教育、工作狀態」作為特徵進行 KNN 填補，確保數據完整性。

### 2.3 戶內資料整理
針對一戶多子女的情況，透過 `family_rank` 標註，將父母問卷中對「特定序位子女」的評價 (如 g26-28 系列) 精確對接到該位子女樣本中。

## 3. 統計檢定與變數篩選
### 3.1 單變量檢定 (Univariate Analysis)
為初步過濾與應變數 (d07) 無關的變數，採用以下非參數檢定：
*   **數值型：** Kruskal-Wallis Test。
*   **二元類別：** Mann-Whitney U Test。
*   **有序類別：** Spearman Rank Correlation。
*   **結果：** 發現「性別 (a01)」、「父母視角之親子感情 (g28c1)」與「父母憂鬱程度 (m02z07_parent)」具有顯著相關。

### 3.2 共線性檢驗 (VIF)
建立線性迴歸偵測自變數間的共線性，確保所有納入模型的變數 VIF 均小於 5，避免模型估計不穩。

## 4. 最終模型與研究方法
### 4.1 方法論：有序羅吉斯迴歸 (Ordinal Logistic Regression)
由於「結婚意願」為 1 (非常想) 到 4 (非常不想) 的有序類別，採用 `MASS::polr` 建立模型。並通過 **比例勝算假設 (Proportional Odds Assumption)** 檢定 (p=0.2275)，證實模型設定正確。

### 4.2 建立變數群組
*   **核心自變數：** 催婚壓力 (整合 d66, d67, d68z10 之二分變數)、16 歲前父母是否分居/離婚。
*   **控制變數：** 性別、子女收入、家庭總收入、工作狀態。
*   **交互作用項：** 催婚壓力 × 父母分居、催婚壓力 × 父母離婚，用以檢驗「家庭解體背景下之催婚」是否產生反彈效果。

## 5. 分析結果摘要
1.  **性別顯著：** 性別 (a01) 在所有模型中均顯著 (p < 0.05)，顯示男女在結婚意願上有結構性差異。
2.  **原生家庭陰影：** 父母在子女 16 歲前「分居」對結婚意願有邊際影響，且在加入交互作用後係數顯現。
3.  **交互作用發現：** 模型 3 顯示「父母分居」與「催婚壓力」的交互項係數顯著，暗示在特定家庭背景下，催婚行為對子女結婚意願的影響路徑會發生改變。
4.  **經濟因素：** 在控制心理與家庭因素後，收入對此樣本群體結婚意願的預測力並不顯著，支持「心理因素亦為不婚關鍵」之假設。
